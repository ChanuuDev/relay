# Relay 디자인 적용 기준

`DESIGN.md`의 Cursor 공개 웹 참고 자료를 Relay의 로컬 세션 기록 화면에 적용합니다. 참고 문서의 관찰값과 Relay에서 결정한 동작을 구분합니다.

## 목적

이전 대화의 세션을 찾고, 작업 맥락을 확인하고, 다음 대화에 전달합니다. 세션의 실행 여부나 시작·종료·중단 상태는 관리하지 않습니다. 목록은 최근 기록순으로 보여 주고 검색과 Provider·Agent·프로젝트 경로 필터를 제공합니다.

## 공통 토큰

원본은 `styles.css`의 `:root`와 `@theme inline`입니다. shadcn 컴포넌트와 화면 모두 같은 의미 토큰을 사용합니다.

| 역할 | 적용값 |
|---|---|
| 화면 배경 | `--background: #f7f7f4` |
| 본문·주요 버튼 | `--primary`, `--foreground: #26251e` |
| 안내·요약 표면 | `--card`, `--muted: #f2f1ed` |
| 보조 버튼 | `--secondary: #e6e5e0` |
| 호버·선택 표면 | `--accent: #ebeae5`, `--selected: #e1e0db` |
| 장식용 주황 | `--brand-accent: #f54e00` |
| 작은 텍스트 링크 | `--link: #b83b00` — 밝은 표면에서 읽을 수 있도록 조정 |
| 카드·입력 모서리 | `--radius: 4px` |
| 주요·보조 버튼 모서리 | `999px` |

원색으로 채운 통계 카드, 과도한 그림자, 회전 장식을 사용하지 않습니다. 선택은 표면색과 얇은 잉크색 선으로 표현합니다. 오류와 서버 연결 표시는 실제 조회 결과에 따른 피드백이며 세션 상태가 아닙니다.

## 서체와 정보 계층

CursorGothic의 공개 재배포 라이선스가 확인되지 않았으므로 포함하거나 원격으로 요청하지 않습니다. Relay는 기존 로컬 서체 `Segoe UI`, `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif`를 명시적으로 선택합니다. CursorGothic과 동일한 서체로 표기하지 않습니다. 코드·식별자는 Cascadia Code/Consolas 계열을 사용합니다.

목록 제목은 18px(모바일 16px), 세션 제목과 요약은 14px, 보조 정보는 11–13px를 사용합니다. 상단 소개 영역과 수동 새로고침 버튼 없이 세션 기록·필터·목록을 바로 표시하며, 조회는 3초마다 자동 갱신합니다. 긴 요약과 경로는 줄바꿈하고, 목록에서 생략한 요약은 상세에서 원문 전체를 보여 줍니다.

## 구성과 동작

- `client.tsx`: 조회 구성, URL 이동, 클립보드 피드백, 검색 단축키와 초점 복귀.
- `workspace-sidebar.tsx`, `context-guide.tsx`: 기록 탐색과 다음 대화에 맥락을 전달하는 안내.
- `session-filters.tsx`, `session-list.tsx`: 필터 입력과 기록 목록.
- `session-detail.tsx`: 개요·기록 이력·세션 연결. 요약·모델·최초 기록·최근 기록·실제 세션 ID를 표시.
- `lib/session-context.ts`: 목록과 상세에서 동일한 맥락 텍스트와 조회 명령을 생성.
- `components/ui/`: 기존 shadcn/Radix 입력·버튼·탭·피드백 컴포넌트.

넓은 화면은 목록과 상세를 함께 표시합니다. 1100px 이하에서는 선택한 상세에 집중하고, 760px 이하에서는 상단 탐색과 단일 열을 사용합니다. 이 반응형 기준은 Cursor의 관찰값이 아닌 Relay의 결정입니다.

`/`로 검색에 초점을 보냅니다. 입력 중이거나 IME 조합 중이면 단축키가 개입하지 않습니다. 세션을 열면 상세, 목록으로 돌아오면 원래 세션 링크에 초점을 돌립니다. 복사 권한이 없으면 원문을 선택할 수 있고 Escape로 닫아 복사 버튼으로 돌아갑니다. 동작 중 강조, 키보드 포커스, 오류 복구, reduced-motion은 Relay의 접근성 규칙입니다.

## 검증

`npm run typecheck`, `npm test`, `npm run build`, `npm run test:web`를 사용합니다. Playwright에서 검색·페이지·연결·요약 복사·복사 권한 거부·키보드 탐색·연결 실패 복구를 확인하고, 1920/1280/1024/760/390/320px에서 상세 내용과 가로 넘침을 검사합니다. 외부 폰트·CDN 없이 실행 파일에 포함된 자산으로 동작합니다.
