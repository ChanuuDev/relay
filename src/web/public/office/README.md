# 사무실 앱 그림

사무실 창(`AppId: office`)이 쓰는 그림이다. 모두 Codex 이미지 생성(sprite-gen `gen`/`gen-set --provider codex`)으로 만들었다.

| 파일 | 내용 | 만든 방법 |
| --- | --- | --- |
| `background.webp` | 1676×938 아이소메트릭 야간 사무실. 위 WORKING, 왼쪽 BLOCKED, 오른쪽 HANDOFF, 아래 DONE 퇴근 로비(INFO 데스크·소파·EXIT 문), 가운데 홀 | 사용자 컨셉 그림을 참조로 사람·말풍선·범례를 지운 빈 사무실을 생성하고, 완료 방은 로비로, 홀의 네 출입구는 문짝 없이 열린 통로(문틀 위 작은 화살표)로 고쳐 그린 뒤 바뀐 곳만 합성, WebP 품질 92 |
| `hq-birch.webp` | 1672×941 자작나무 사옥(낮). 왼쪽 가운데 큰 나무가 선 햇살 아트리움 홀, 오른쪽 절반의 벤치 책상 WORKING, 왼쪽 위 BLOCKED 집중실, 아래 가운데 유리 회의실 HANDOFF, 왼쪽 아래 EXIT 유리문 로비 | 야간 본사를 화풍·크기 참조로만 주고 평면·좌석 배치를 새로 설계하게 해 생성, WebP 품질 92 |
| `hq-oak.webp` | 노을 지는 도시 전망 펜트하우스의 오크 사옥. 왼쪽 위 WORKING, 오른쪽 위 원탁 HANDOFF, 오른쪽 BLOCKED, 가운데 대각선 라운지 홀, 아래 엘리베이터 로비 | 같은 방법으로 생성, WebP 품질 92 |
| `worker.png` | 캐릭터 아틀라스. 51×64 칸, 몸체 2종 × 8줄(앞·뒤 대기, 앞·뒤 걷기, 앉기, 타이핑, 앉아 쉬기, 등 잡혀 버둥거리기) | 보라 머리·하늘 셔츠·남색 바지의 재색칠용 베이스 → sprite-gen 방향 앵커(down45·up45) → 동작 행. 원본 배율로 추출한 뒤 머리 높이로 행 배율을 맞추고 40색 공용 팔레트로 줄였다 |
| `badges.png` | 머리 위 상태 배지 5개(작업 중 말줄임, 막힘 느낌표, 인계 화살표, 완료 체크, 종료 잠) | 한 장에 생성한 뒤 조각마다 15px 높이로 줄였다 |

캐릭터는 세션 ID로 정해지는 색(머리·셔츠·바지·피부)으로 브라우저에서 다시 칠한다(`src/web/lib/office/look.ts`).
`worker.png`의 팔레트 중 어느 색이 어느 부위인지와 야간 본사의 좌석·걷는 길 좌표는 `src/web/lib/office/office-data.ts`에, 두 사옥의 좌표는 `hq-birch.ts`·`hq-oak.ts`에 있다. 사옥 좌표는 저장소 밖 작업 폴더(`output/office/hq`)에서 격자 확대 그림과 캐릭터를 얹은 미리 보기로 찍고 `build.py`로 길이 이어졌는지·좌석이 구역 안인지 검사해 옮겼다.
그림을 바꾸면 그 파일의 `?v=` 판 번호를 올린다.
