# 사무실 앱 그림

사무실 창(`AppId: office`)이 쓰는 그림이다. 모두 Codex 이미지 생성(sprite-gen `gen`/`gen-set --provider codex`)으로 만들었다.

| 파일 | 내용 | 만든 방법 |
| --- | --- | --- |
| `background.webp` | 1676×938 아이소메트릭 야간 사무실. 위 WORKING, 왼쪽 BLOCKED, 오른쪽 HANDOFF, 아래 DONE 퇴근 로비(INFO 데스크·소파·EXIT 문), 가운데 홀 | 사용자 컨셉 그림을 참조로 사람·말풍선·범례를 지운 빈 사무실을 생성하고, 완료 방 부분만 잘라 로비로 고쳐 그린 뒤 바뀐 곳만 합성, WebP 품질 92 |
| `worker.png` | 캐릭터 아틀라스. 51×64 칸, 몸체 2종 × 8줄(앞·뒤 대기, 앞·뒤 걷기, 앉기, 타이핑, 앉아 쉬기, 등 잡혀 버둥거리기) | 보라 머리·하늘 셔츠·남색 바지의 재색칠용 베이스 → sprite-gen 방향 앵커(down45·up45) → 동작 행. 원본 배율로 추출한 뒤 머리 높이로 행 배율을 맞추고 40색 공용 팔레트로 줄였다 |
| `badges.png` | 머리 위 상태 배지 5개(작업 중 말줄임, 막힘 느낌표, 인계 화살표, 완료 체크, 종료 잠) | 한 장에 생성한 뒤 조각마다 15px 높이로 줄였다 |

캐릭터는 세션 ID로 정해지는 색(머리·셔츠·바지·피부)으로 브라우저에서 다시 칠한다(`src/web/lib/office/look.ts`).
`worker.png`의 팔레트 중 어느 색이 어느 부위인지와 좌석·걷는 길 좌표는 `src/web/lib/office/office-data.ts`에 있다.
그림을 바꾸면 그 파일의 `?v=` 판 번호를 올린다.
