# 사무실 앱 그림

사무실 창(`AppId: office`)은 그림 한 장 위에 좌표를 덧대지 않고, 쿼터뷰(2:1 아이소메트릭) 격자 위에 바닥 칸·벽 조각·문·가구·소품 스프라이트를 하나씩 놓아 그린다.
칸 하나가 1m(화면 64×32)이고, 벽과 가구가 칸을 막아 캐릭터가 통과하지 않으며, 그릴 때는 바닥 넓이(격자 상자)로 앞뒤를 가려 벽·유리·가구와 바르게 겹친다.
모든 그림은 Codex 이미지 생성(sprite-gen `gen --provider codex`)으로 만들었다.

| 파일 | 내용 | 만든 방법 |
| --- | --- | --- |
| `kit-night.png`·`kit-birch.png`·`kit-oak.png` | 사옥마다 그림 묶음(아틀라스): 가구·소품 21종, 벽 조각(벽·유리 칸막이·낮은 벽·출입구 인방, 두 방향), 기둥, 벽 장식(창·출구 유리문/엘리베이터 닫힘·열림·화이트보드·TV·코르크 보드·그림·시계·벽등·흡음판, 두 방향) | 사옥 그림을 화풍 참조로 가구·소품·의자 시트(쿼터뷰, 마젠타 키)와 벽 장식 시트(정면, 초록 키)를 생성 → `sprite-gen cutout --decontam palette`로 키 색 번짐 제거 → 덩어리별로 잘라 가구는 바닥 넓이(예: 책상 2×1)에 맞춰 줄이고, 벽 장식은 정면 그림을 벽 면 기울기로 붙이고, 벽 조각·기둥은 벽 재질 그림으로 칸 하나 길이씩 그렸다 |
| `floors-night.png`·`floors-birch.png`·`floors-oak.png` | 바닥 재질(홀·구역마다 하나). 정사각형 재질이 이음매 없이 되풀이되며 몇 칸을 덮는지는 `kit-*.ts`의 `floorTiles`에 있다 | 재질 시트를 생성 → `sprite-gen background-tile`(가로·세로)로 이음매 없게 → 큰 얼룩을 눌러 바둑판처럼 보이지 않게 했다. 줄눈이 있는 석재는 시트 그대로 쓴다 |
| `backdrop-night.webp`·`backdrop-birch.webp`·`backdrop-oak.webp` | 사무실 아래에 까는 사옥 배경: 야간 본사는 별이 뜬 밤하늘과 저 아래 반짝이는 도시, 자작나무 사옥은 요정이 살 법한 거대한 나무(문·창·랜턴·흔들다리·빛나는 버섯)가 선 숲, 오크 사옥은 노을 진 대도시 스카이라인 | 지금 사옥 화면을 색 참조로 주고, 가운데는 사무실이 덮으니 차분하게 두고 풍경은 가장자리·귀퉁이에 두도록 생성(1672×941) → WebP 품질 84. 화면 가득(cover) 깔고 확대·이동할 때 사무실보다 덜 움직여 멀리 있는 풍경처럼 보인다. 사무실 아래에는 떠 있는 그림자를 깐다 |
| `worker.png` | 캐릭터 아틀라스. 몸체 12종(반소매 셔츠 2종과 메이드복·유치원복·츄리닝·정장·오피스룩·후드티·니트·원피스·실험 가운·세일러 교복) × 9줄(앞·뒤 대기, 앞·뒤 걷기, 앉기, 타이핑, 앉아 쉬기, 등 잡혀 버둥거리기, 소파에 앞 보고 앉기), 몸체마다 한 구역 | 보라 머리·하늘(주 옷감)·남색(둘째 옷감)의 재색칠용 베이스를 처음 캐릭터를 화풍 참조로 생성 → sprite-gen 방향 앵커(down45·up45) → 동작 행. Codex 생성 모델은 `gpt-6.1-sol`, 추론 수준은 `high`다. 원본 배율로 추출한 뒤 행 배율을 맞추고(서 있는 행은 전신 키, 앉는 행은 앉기 첫·마지막 칸 키, 소파는 머리 높이, 버둥거리기는 머리 넓이: 트윈테일·긴 머리는 자세마다 흔들려 머리 높이로는 맞지 않는다) 몸체마다 36색 팔레트로 줄였다(처음 두 몸체는 픽셀 그대로). 만드는 스크립트는 저장소 밖 `output/office/cast`(`roster.py`·`requests.py`·`motion.sh`·`build_cast.py`)에 있다 |
| `pets.png` | 반려동물 아틀라스. 토끼·다람쥐·고양이·페럿·판다·강아지·거북이 × 8줄(앞·뒤 대기, 앞·뒤 걷기, 울기, 뛰기, 잠, 반기기) | 같은 화풍 참조로 네 발 동물(`--body-plan quadruped`) 정지 그림 → 방향 앵커 → 동작 행. 원본 배율로 추출한 뒤 몸 넓이로 행 배율을 맞추고 종마다 정한 키(14–27px)로 24색 팔레트에 줄였다 |
| `badges.png` | 머리 위 상태 배지 5개(작업 중 말줄임, 막힘 느낌표, 인계 화살표, 완료 체크, 종료 잠) | 한 장에 생성한 뒤 조각마다 15px 높이로 줄였다 |

- 자작나무 사옥은 숲속 사옥이다: 그림 묶음에 카페 바·공용 테이블·몬스테라·사다리 선반·푸프·부클레 의자·요정 조명 나무·아치 책장·레몬 나무, 위에서 내려다본 러그 4종(바닥 마름모로 투영해 바닥 층에 깐다), 아치 창·이끼 벽·고사리 액자·랜턴 같은 벽 장식, 나무 판벽(`Y`·`B`)과 판재 난간, 헤링본 바닥이 더 있고, 바닥 판 옆면 대신 이끼·흙·늘어진 뿌리가 보이는 떠 있는 섬 옆면 띠(`kit.edge`)를 모서리를 따라 잇는다.
- 사옥 지도(바닥 글자·벽 줄·장식·가구·좌석·홀 자리)는 `src/web/lib/office/map-night.ts`·`map-birch.ts`·`map-oak.ts`에 손으로 쓴다. 벽 줄 글자는 `W` 벽, `Y` 나무 판벽, `G` 유리, `L` 낮은 벽, `D`·`B`·`d` 출입구, `O`·`o` 트인 통로, `E` 출구 자리다.
- 그림 묶음의 자리·기준점은 `kit-*.ts`에 있고 저장소 밖 작업 폴더(`output/office/kit`)의 `build_kit.py <사옥>`이 만든다. 손으로 고치지 않는다.
- 지도는 `iso.ts`의 `planWorld`가 걷는 길·좌석·구역으로 풀고, `world.ts`가 바닥과 벽·가구를 한 층으로 그려 둔 뒤 매 프레임 캐릭터와 그 앞에 와야 할 벽·가구만 앞뒤 순서로 다시 그린다. 사람 키보다 높은 벽 뒤에 가린 캐릭터는 실루엣으로 보인다.
- 끄는 동안의 표시(앉을 좌석 칸, 자리를 맞바꿀 동료 머리 위 ⇄)와 실제로 놓을 때의 결과는 `OfficeSim.dropTarget` 하나로 정한다.
- 캐릭터는 세션 ID로 정해지는 몸체(옷차림·머리 모양)와 색(머리·주 옷감·둘째 옷감)으로 브라우저에서 몸체 구역만 다시 칠한다. 피부는 모든 캐릭터에 밝은 톤 하나를 적용한다(`look.ts`). 칸 정보는 `office-data.ts`, 반려동물 칸 정보는 `pet-data.ts`에 있다.
- 그림을 바꾸면 `kit-*.ts`의 `?v=` 판 번호(빌드 설정의 `version`)를 올린다.
